# People's Priority AI

People's Priority AI is an AI-powered citizen feedback and constituency development platform that enables citizens to submit suggestions through text, images, and voice. The platform uses AI to categorize suggestions, analyze priority levels, generate summaries, and help administrators make data-driven decisions for effective public development.

## Live Demo

Live Website: https://peoples-priority-ai.onrender.com/

## Features

* Citizen registration and secure login
* Submission of suggestions through text, images, and voice
* AI-based category classification
* AI-based priority score generation
* AI-generated suggestion summaries
* Duplicate and demand analysis
* Location-based suggestion visualization
* Interactive map and demand hotspots
* Administrator dashboard for managing citizen suggestions
* Suggestion status management
* Cloud-based storage for uploaded images and voice recordings

## Purpose

The platform aims to improve communication between citizens and administrators by organizing public feedback, identifying high-priority issues, and supporting data-driven decision-making for constituency development.
